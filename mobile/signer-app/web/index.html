reference driver · detecting…
This is a reference driver, not a shipped phone app. The mobile OS image is UNBOOTED. The signing key never leaves the device, but this is a software keystore — not a hardware wallet; a rooted / malware phone can steal the key and forge this screen. Every signature needs per-sign user presence — there is no blanket auto-approve. Unaudited scaffold. This is not "Postern OS"; the community edition is "Postern for postmarketOS — community edition". The coin is not a security. Nothing here is "100% private/secure". v1 is LOGIN-ONLY — the only shipped flow is a wallet-login signature; the value-transfer flow below is a reference demo, not a shipped v1 path.

1 · Pair with the desktop

The phone is the trust root. Scan (or paste) the desktop's QR payload, then compare the 6-digit SAS on both screens. If they differ, someone may be intercepting you — abort. (Reference pairing: the real ceremony is the PQ-hybrid postern-pairing handshake; here the SAS is derived deterministically from the payload so the compare step is faithful.)
