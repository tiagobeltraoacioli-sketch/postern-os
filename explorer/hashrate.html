How this is computed — and why it is only an estimate

  • A model, not a measurement. To mine a block a candidate must clear both gates, so expected evaluations per block ≈ [2^256 / (target + 1)] × 8^k — the hashcash term (target decoded from bits) times the SIS-gate term. Hashrate ≈ Σ evaluations ÷ elapsed time over the window. Real hashrate is unobservable; this infers it from difficulty, the gate width, and timing.
  • Why the SIS gate is folded in. Bloch's hashcash target is deliberately loose — most of the work is the lattice gate, so a hashcash-only estimate would read near-zero and mislead. Each of the k residual coefficients must land under β = q/16 (~1 in 8), so a valid candidate is ~8^k rarer (k is now a difficulty-driven ramp: k=4 today → ~4096×, up to k=8 → ~16.7 million×; the page reads the live width when the node exposes it). This assumes uniform residuals — a modelling assumption, not a proof.
  • Single vantage point. The blocks come from the one node you query, not a global view. A different node may report different recent blocks.
  • Noisy at low hashrate. With few miners and long gaps, per-block numbers swing wildly — hence the smoothing. Treat the trend, not any single point, as meaningful.
  • Unaudited mainnet beta, 51%-attackable at this hashrate; the coin carries no value claim and is not a security.

Standing disclosures

This chain is a mainnet beta — a designation, not a security claim: unaudited (audit contracted, not done), with very few nodes and low hashrate — 51%-attackable. The Module-SIS gate is a difficulty-driven k-ramp (node v0.1.0-alpha2): k=4 today, rising toward k=8 as the network's own difficulty grows and easing back if hashrate falls. It is not a security claim by itself (real security is cumulative SHAKE-256 hashcash work — raising k adds no cryptographic hardness at β=q/16). A brand-new node can sync from genesis or fast-sync from the optional signed snapshot. Whatever network string a node reports, treat confirmations as reversible.

The coin is not a security and not an asset — it carries no value claim. No token sale, no listing effort, no market-making, no price. A 17% founder premine is disclosed in full. Do not attach value.

The Bloch-SIS-PoW protocol is ownerless and is not a Postern Labs product; there is no official node, site, or explorer. This explorer is one independent tool on that commons, by Postern Labs. It lives at gitlab.com/blochsispow-group/BlochSISPoW-project (shown as text on purpose — there is no official site to link to).
