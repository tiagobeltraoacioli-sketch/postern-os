What this page can — and cannot — tell you

  • Peer counts are single-vantage. Each number below is what one node reports about its own peer connections — not a global crawl, census, or "network size". Other nodes may see more, fewer, or different peers.
  • There is no authoritative node registry. The protocol is ownerless; nobody can enumerate "all nodes". The vantage points you add below are user-supplied, not an official list.
  • Numbers are self-reported by each node's RPC and are not independently verified by this page. A node can claim any network string; whatever it claims, treat this chain as a nascent, unaudited, 51%-attackable mainnet beta whose coin carries no value claim.

Standing disclosures

This chain is a mainnet beta — a designation, not a security claim: unaudited (audit contracted, not done), with very few nodes and low hashrate — 51%-attackable. The Module-SIS gate is a difficulty-driven k-ramp (node v0.1.0-alpha2): k=4 today, rising toward k=8 as the network's own difficulty grows and easing back if hashrate falls. It is not a security claim by itself (real security is cumulative SHAKE-256 hashcash work — raising k adds no cryptographic hardness at β=q/16). A brand-new node can sync from genesis or fast-sync from the optional signed snapshot. Whatever network string a node reports, treat confirmations as reversible.

The coin is not a security and not an asset — it carries no value claim. No token sale, no listing effort, no market-making, no price. A 17% founder premine is disclosed in full. Do not attach value.

The Bloch-SIS-PoW protocol is ownerless and is not a Postern Labs product; there is no official node, site, or explorer. This explorer is one independent tool on that commons, by Postern Labs. It lives at gitlab.com/blochsispow-group/BlochSISPoW-project (shown as text on purpose — there is no official site to link to).
