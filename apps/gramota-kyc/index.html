Gramota · owner / manager identity KYC

The person→entity binder for Postern Enterprise onboarding. It ties you to the company that holds a DUNS number — so nobody registers a corporate license against your company's public DUNS.

Privacy — what leaves this device

On-device by construction. Your document images and the text read from them (OCR, names, numbers — any PII) never leave this device and never reach a Postern server. The only network call is the minimal verdict — booleans, matched field names (never their values), and an assurance level — POSTed to /license/review on this origin (connect-src 'self'; the server tripwire rejects anything more).

A document read is not proof of authority. OCR proves text was extracted, not that a document is authentic, current, or genuinely grants authority. UNAUDITED reference prototype; not legal advice. Any future billing is fiat — the coin is never billed.

The honest caveat: this is defense-in-depth, not "100% private" and not "100% secure." Your images and typed fields live in this page while it is open, so anyone who can use this unlocked device — or a compromised browser or OS — can read them, and the minimal verdict is a real request to this origin. No web page can promise otherwise.
