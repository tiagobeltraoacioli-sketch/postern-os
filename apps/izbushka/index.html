This is the Izbushka task portal. The Yagabona Rust daemon — the part that runs tasks, enforces the Threshold Test at the runtime boundary, and writes the append-only SHAKE-256 audit trail — is not built. This page persists manifests to your browser's localStorage as a stand-in store; on Postern OS the daemon reads real .toml files under ./izbushka/tasks/. The verdicts shown here are a PREVIEW mirror of the daemon's rejection rules — the daemon is authoritative and fail-closed. No network, no telemetry: the portal opens no connections. Named Yagabona / Izbushka (coined marks) — never the registered "Baba Yaga" word mark.

Speak the ritual, and the hut turns its door to you.

A scheduled task runs only when you have spoken an explicit, scoped, expiring capability grant — a task manifest. No formula, no door. Declare a task, review Yagabona's threshold check, then grant.

    Privacy — what leaves this device
    
    
      
    Nothing leaves. This portal opens no network connections — connect-src 'none', no telemetry, no phone-home, no account. Your task manifests persist only in this browser's localStorage, on this device. There is no BYO-key or AI path here; no words are sent to any model.
    
      
    The honest caveat: this is defense-in-depth, not "100% private" and not "100% secure." localStorage is readable by anyone who can open this browser profile or unlock this device, and a compromised browser or OS can read it too. No web page can promise otherwise.
