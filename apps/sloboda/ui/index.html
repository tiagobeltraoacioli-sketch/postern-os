⚠ Read this before you enter Android

This is the non-attestable escape-hatch tier. It runs a full Google/AOSP Android userland in a Waydroid container. Entering Android means data leaves the sealed base.

Play Integrity STRONG will fail. Banking apps, Google Wallet/Pay, and DRM video (Widevine L1) detect the environment and refuse to run. That is by design, not a bug we can fix.

Not covered by the Postern Seal. The Android image is mutable state pulled at waydroid init, so os_roothash says nothing about what runs inside it. The coin is worthless; personal use is free. This is not legal advice.

UNTESTED scaffold. There is no Waydroid in the build sandbox, so nothing here has ever booted an Android container. This page cannot talk to Waydroid — it only composes the commands the sloboda wrapper runs on-device.
