Org policy & licensing

This console governs only the Business edition — additive, org-managed capabilities layered on top of the free personal suite. It never disables a personal app or reaches a person's personal-app data. Verification is offline (real Ed25519, no network); there is no per-user account and no per-user login.

Corporate master offline · real Ed25519 · no server

A company with a DUNS number mints one vendor-signed master bundle on posternlabs.com (/license/master). Paste that bundle below. This console verifies the vendor → master Ed25519 chain offline against the licensing lib's pinned public key, then unlocks the Business edition for unlimited users for the evaluation window. Leaving it blank runs the free freemium tier (up to 3 desktops, 2 years).

The bundle carries master_private_key_pkcs8 — the org's own signing key. It stays on this device; it is used only to mint sub-accesses locally and is never sent anywhere. The only network call this console can make is the optional, same-origin public CRL fetch below (connect-src 'self'); the vendor's private key never leaves posternlabs.com.

Sub-access — delegate to users & teams

The master holder mints signed sub tokens (Ed25519, signed by the org's master key) for individual users or teams — unlimited subs, each with sub.exp ≤ master.exp. A sub-user installs their token; their app verifies the offline chain vendor → master → sub. No per-user account, no server login, no telemetry.

License revocation (CRL) vendor-signed · anti-rollback · offline-verified

A leaked master or sub can be revoked by posternlabs.com without breaking offline verification. This console fetches the vendor-signed, versioned CRL from /license/status (same-origin, public — the fetch reveals only that you checked), verifies it against the same vendor public key it already trusts, prefers the higher version (anti-rollback), honours the soft-offline freshness window, and refuses a revoked master or sub. The CRL only ever revokes, never grants; the personal-free base is never affected. Air-gapped? Paste a CRL below — no network needed.

No CRL loaded — offline, best-effort. A valid license stays valid until a newer, fresher CRL revokes it.
